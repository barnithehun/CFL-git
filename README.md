# CFL: Bankruptcy Resolution and the Macroeconomics of Cash Flow-Based Lending

This repo holds the code and paper for a project on how bankruptcy resolution shapes firms' use of cash flow-based (CF) and asset-based (AB) debt. It also asks what lowering reorganization costs, for example through the SBRA, does to firm dynamics and aggregate output. The current paper is `Latex codes/Main/main5.tex`.

## Layout

| Folder | Contents | Edit? |
|---|---|---|
| `Data Replication/` | R code for the empirical facts and the calibration targets → [README](Data%20Replication/README.md) | **Yes**: all data work goes here |
| `Julia codes/Model Replication/` | Working copy of the structural model → [README](Julia%20codes/Model%20Replication/README.md) | **Yes**: all model work goes here |
| `Julia codes/FinalVers/` | Final model scripts used for the paper (`Baseline.jl` is the main one) | No, reference only |
| `Julia codes/Functions/` | Solver (`FCmodel/`) and result and plot helpers for `FinalVers/` | No, reference only |
| `Julia codes/Miscellaneous/`, `Model versions/`, `Practice codes/` | Older versions and experiments | No, not used |
| `Latex codes/` | Paper (`Main/`), notes, presentations, extended abstracts, and paper figures (`Plots/`) | No |
| `CalibResults/` | Older calibration runs (V1–V5) | No |
| Repo root `.png` / `.xlsx` | Outputs saved by earlier runs of the `FinalVers/` scripts | No |

## Rules for editing

These rules apply to anyone working in the repo, including Claude.

- Create and edit files only in `Data Replication/` and `Julia codes/Model Replication/`. Everything else is the original code and paper: do not edit, move or delete it.
- Data work goes in `Data Replication/`, and model work goes in `Julia codes/Model Replication/`.
- To change an original file, copy it into the matching replication folder and edit the copy.
- Read a replication folder's README before editing in it. The Model Replication README has the rules on keeping the original code structure.

## How to replicate

1. **Data:** follow `Data Replication/README.md` to get the facts and the calibration targets.
2. **Model:** follow `Julia codes/Model Replication/README.md` to solve, speed up and recalibrate the model.

## Requirements

- Julia 1.12.7, with the environment in `Project.toml` / `Manifest.toml` at the repo root.
- R and the packages listed in the Data Replication README.
- A WRDS account for Compustat and Capital IQ.
- Not in git: `.RDS`, `.csv`, `.xlsx`, `.dta`, `.zip` and `.pdf` files are gitignored. The data files are regenerated by the Data Replication scripts.
